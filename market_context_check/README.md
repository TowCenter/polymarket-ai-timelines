# Market Context sweep — is 107 really the ceiling?

## Question

The published dataset in this repo covers **107 markets** with "Market Context" timelines, collected May 12–July 15, 2026. We want a rough count of how many Polymarket events currently expose Market Context content — is it ~100, or is it much larger?

## What "Market Context" means (and open questions)

On a Polymarket event page, "Market Context" is a section that displays AI-generated commentary about the market. In the collection window for this repo's dataset, that content was **per-annotation timeline entries** (headline + summary + source citations), attributed by Polymarket's API to the third-party service [Linkup](https://www.linkup.so).

Since then, at least one thing has changed:

- The **`eventMetadata.context_description`** field on Gamma's `/events` endpoint now carries a single-paragraph event summary with `context_updated_at` and `context_requires_regen` fields. No citations in that payload.
- The event page HTML contains a locale key called **`grokEventSummary`**, suggesting the paragraph is generated by Grok (xAI), not Linkup.

**Confirmed by looking at page HTML**: both features coexist.
- On `balance-of-power-2026-midterms` (in the historic 107): the event page HTML contains **1,336 mentions of "linkup"** and only 1 mention of "grok". Each Linkup annotation entry is inlined in the page as JSON with fields like `"source":"linkup"`, `sources`, `outcome`, `priceBefore`, `priceAfter`, `summary`, `timestamp`.
- On `xi-jinping-out-before-2027` (not in the historic 107): 0 mentions of "linkup". Its `eventMetadata.context_description` is a Grok paragraph.

So: **Grok generates the single-paragraph summary; Linkup still generates the per-annotation timeline**. Different endpoints/fields, same UI section. The `eventMetadata.context_description` count answers "how many events have Grok context"; the count of `"source":"linkup"` occurrences on the event page answers "how many events have Linkup timelines" — the same feature the historic 107 dataset measures.

## What this sweep counts

Two separate signals:

- **(A) Grok single-paragraph context:** `eventMetadata.context_description` non-empty on the Gamma `/events` endpoint.
- **(B) Linkup per-annotation timeline** (the historic 107's feature): count of `"source":"linkup"` in the SSR-rendered event page HTML at `polymarket.com/event/<slug>`. Non-zero = event has a Linkup timeline.

## Method

1. Paginate `https://gamma-api.polymarket.com/events?order=volume&ascending=false` in filter buckets to work around Gamma's offset cap of 2,100. Buckets used:
   - `closed=false, archived=false` — top-2,100 open events (floor ~$16k, near-complete).
   - `closed=true, archived=false` — top-2,100 closed events (floor $4M).
   - `closed=true, archived=false, volume_min=X, volume_max=Y` in 12 sub-buckets covering the $1M–$4M range that falls below the closed top-2,100 cap. Each sub-bucket is under the cap.
   - Below $1M closed: skipped. Observed Linkup floor is $967k; below that the population is dominated by sports outcomes with no news attribution.
2. Union all buckets by event `id`. Record Grok `context_description` presence.
3. For every event pulled, fetch the SSR event page HTML and count `\"source\":\"linkup\"` occurrences (escaped-quote form since annotations are embedded in a JS string literal).
4. Cross-reference against the 107 slugs in the historic `data/all_citations_full.csv`.
